engineering references. They demonstrate distinctions between entry, persistence,
occupation and representation closure. They do not implement a cancer model or
inherit biological qualification from OoL-MVS.

Candidate backends are recorded in graph/model_classes.jsonl. Use a MethodApplicability
record and a frozen ModelInstance before making a claim-bearing application. No
import of sources/methods/ool_mvs code occurs during build or validation.
