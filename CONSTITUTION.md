# OoC graph constitution — v0.1

## 1. Jurisdiction

The graph represents the Origin-of-Cancer research programme. ESET, RHKG, OoL-MVS,
Permansson, FFBBP and MCM-HMWH are bounded source dependencies, not annexed theories.
The programme remains pre-formalization. This constitution governs representation
and admission procedure; it cannot manufacture biological truth.

## 2. Four distinct layers

Authored Markdown records reasoning. Authored normalized graph records encode
explicit objects and adjudications. Evidence and source artifacts provide the basis.
Generated views are reproducible projections with no independent authority.
Drive is a raw-artifact warehouse, not a second writable scientific-state registry.

## 3. Objects before files

Scientific IDs are independent of document names, array positions and status.
Materially different meanings require a new concept or an explicit revision decision.
Frozen model/protocol/data identities cannot be mutated under old results.

## 4. Scope before status

A verdict is partitioned by subject, axis, facet, scope and frozen model identity.
No “latest wins” rule. Explicit supersession only applies within a matching partition.
Incomparable surviving verdicts remain a conflict, not an automatic resolution.

## 5. Evidence chain

LiteratureSource -> SourceLocator -> EvidenceObject -> EvidenceAssessment ->
Claim/Transition/Route -> Verdict. Citation presence alone carries no causal weight.
Repeated citations to one cohort are not independent replication.

## 6. Biological distinctions

Capability, entry, establishment, persistence, ancestry, causal constitution,
observation, certificate integrity and clinical actionability remain distinct.
Transitions are first-class nodes with context and evidence. Graph reachability is
not observed history. A feedback cycle in a drawing is not a maintained biological loop.

## 7. Mathematical distinctions

Declare the estimand before selecting a backend. Pathwise objects precede probability.
State/history sufficiency, observation adequacy, target identification, method
applicability and numerical verification are separate obligations. Exact and
finite-horizon statements must not be exchanged.

## 8. Authority is bounded

Project governance controls wording and admission policy, not empirical truth.
MVCL v1.3 controls imported mechanism vocabulary only. Pathology references control
reference classifications, not a mathematical malignant set. Software and formal
proofs control only their exact verified statements.

## 9. Integrity and completeness

Every repository file receives a declared class; every source-backed object a locator;
every relation typed endpoints and provenance. Physical accounting, document
coverage, paper extraction, model applicability and scientific closure are reported
separately. Open scientific gaps do not make engineering CI fail.

## 10. Non-promotion and memory

The claim firewall is mandatory. Never fill missing results to make a gate green.
Failed hypotheses/results are preserved; explicit typed successor relations record
repairs. Deletion of immutable baseline sources or unacknowledged removal of
negative scientific records is an integrity error.

## 11. Confirmation discipline

Freeze model, phenotype/target definition, observation mapping, selection procedure,
thresholds, nulls, data partition, metric and intended scope before confirmation.
Post-outcome changes are a new construction requiring new confirmation, not a rescue.

## 12. Publication and execution

No imported code runs during graph build. Routine CI has read-only repository
permissions and no scientific promotion powers. Releases identify exact subject and
graph digests; Git commit identity is attached externally, avoiding self-hash cycles.
No clinical action is authorized. Amend this constitution only with explicit rationale,
impact analysis, tests and a reviewed version change.
