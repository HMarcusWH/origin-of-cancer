# Documentation and state authority

| Surface | Responsibility | Prohibited inference |
|---|---|---|
| `sources/baseline/`, `sources/methods/` | Frozen source/provenance snapshots | New current scientific authority from a filename |
| `docs/`, root constitution and theory | Authored reasoning and operating contracts | Unsupported empirical promotion |
| `graph/` | Canonical structured objects, scopes and reviewed decisions | Treating record presence as evidence |
| `schema/`, `config/`, `resolver/` | Representation/admission rules | Automatic biological adjudication |
| `modeling/` | Scoped implementations and numerical demonstrations | Simulated observations as real oncology |
| `generated/`, `manifest.json` | Deterministic reviewer projections | Becoming a second editable source of truth |
| `releases/` | Frozen packaging identity and integrity | Clinical qualification |

Long-form prose is authored once. Machine status is authored in structured records;
status tables in generated documents are not edited by hand. A mismatch is a defect
requiring explicit correction, not a silent overwrite. Source transcriptions retain
the source's own caveats, terminology and historical inconsistencies.

`CURRENT_STATE.md` is navigation only. The graph resolver, source evidence and scoped
adjudications determine the recorded state. No authority owns “all cancer truth”.

Decision owner at bootstrap: Marcus Hermansson. AI assistance is not independent
scientific review. Branch protection is a repository-admin setting and is not
established merely by this document or a CODEOWNERS file.
