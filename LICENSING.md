# Licensing and redistribution

No blanket software or documentation license is granted by this bootstrap. The
owner previously deferred licensing to a deliberate later decision. This file does
not replace that decision and does not relicense third-party works.

The repository contains user-directed transcriptions of the user's authored research,
source citations/metadata, new research documentation, and engineering code. Publisher
article PDFs and restricted raw datasets are not included. Imported upstream method
code retains its provenance and is not claimed as newly authored OoC code.

Before broader redistribution, resolve code/document/data licenses separately and
record them in a reviewed change. See `NOTICE.md` for attribution and extraction limits.
