# Tissue governance

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

Use governance only as operational shorthand for restoring, competitive and containment mechanisms: architecture, differentiation, death/senescence, competition, immunity and resource/mechanical constraints. Do not anthropomorphize tissue or treat a generic governance variable as measured.
