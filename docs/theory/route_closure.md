# Route closure

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

A route is more than a set of plausible mechanisms. Declare input/output handoffs, ancestry, temporal compatibility, context, observation basis, unresolved segments and alternative histories. Use SAME_SYSTEM, VALIDATED_BRIDGE or SYNTHESIS_ONLY witness modes. Cross-study synthesis is useful but not an observed end-to-end route.
