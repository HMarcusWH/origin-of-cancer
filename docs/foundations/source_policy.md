# Foundation source policy

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

Each load-bearing theory needs a direct canonical source, a modern formulation, boundary-setting or hostile evidence, explicit scope and a strongest-allowed claim. Reviews guide discovery; primary studies carry mechanistic findings. Preprints and review-level universality claims remain provisional. Bibliographic verification, extraction and scientific appraisal are separate statuses.

## Status and traceability

This document is a baseline working synthesis of the supplied programme/method sources, not a completed source appraisal or a new empirical result. See the root documentation-authority contract and source manifest. Scientific promotion requires explicit graph evidence and scoped adjudication.
