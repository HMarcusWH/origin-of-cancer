# Paper packet schema

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

Preserve identity (DOI/PMID/PMCID/version), source type, actual boundary observed versus assumed, species/tissue/age/genotype/exposure/stage, origin object, transition, time design, lineage, space, candidate mechanism, perturbation, nulls, positive/negative outcome balance, modalities, mathematical formalism, identification limits, OoC relevance, strongest allowed claim, forbidden overclaim, kernel consequence and contradictions. Each finding needs its own exact source locator.

## Status and traceability

This document is a baseline working synthesis of the supplied programme/method sources, not a completed source appraisal or a new empirical result. See the root documentation-authority contract and source manifest. Scientific promotion requires explicit graph evidence and scoped adjudication.
