## Explicit non-import

## Transfer rule

This is a methodological source, not independent oncology evidence. An imported
mathematical result requires an exact statement/locator, assumptions, representation
mapping, application domain, and an applicability assessment. Numerical execution,
formal proof, and biological validation remain separate. New source versions require
an import delta and do not inherit old experimental qualifications.
