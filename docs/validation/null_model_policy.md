# Null models

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

Select serious alternatives appropriate to the target: neutral drift, age-only, mutation-count, selection-only, niche-as-consequence, pathology/static-risk baselines, platform artifacts, mis-association and observation-process alternatives. No single universal negative control proves absence of confounding. Register known-positive, assay, structural-null and comparator controls separately.
