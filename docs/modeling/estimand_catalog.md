# Estimand catalog

Catalogue only; target sets, horizons and operators require biological and observation justification.

| Estimand | Definition obligation |
|---|---|
| First entry time | Entry to a predeclared target, with time zero and non-entry conventions. |
| Establishment time | Time a separately declared establishment rule is satisfied; no universal threshold. |
| Uninterrupted persistence probability | Probability of staying within the target throughout the declared horizon. |
| Establishment probability | Probability of satisfying the declared establishment event by the horizon, not automatically persistence. |
| Extinction probability | Declared population/ensemble and extinction boundary. |
| Transition hazard | Conditioning risk set, clock, competing exits and sampling process. |
| Occupation / state occupancy | Fraction of time or state probability; distinguish time average from uninterrupted residence. |
| Episode duration | Entry-to-next-exit sojourn, conditional entry and censoring. |
| Recurrence / return | Re-entry after exit with origin/source specification. |
| Route probability | Probability of declared route class under a justified path law. |
| Route flux | Model-defined current; not synonymous with probability or reachability. |
| Action / rate functional | Only under an applicable rare-event construction. |
| Intervention contrast | Predeclared functional under two explicitly typed interventions. |
| Ancestry-related functional | Target event/quantity for genealogical continuity; not mediation. |
| Identification set | Set of target values compatible with data, model set and assumptions. |
| Reduction error | Error for a declared target under a scale projection, norm and horizon. |
