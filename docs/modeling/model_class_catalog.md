# Candidate model-class catalog

No class is selected as a universal cancer process.

| Class | Applicability obligations |
|---|---|
| Finite-state Markov chain | Sufficient present state; stochastic nonnegative transition matrix; declared clock. |
| Continuous-time Markov chain | Valid generator; non-explosion; justified Markov state. |
| Semi-Markov process | Declared state-dependent holding times and transition law. |
| Hidden semi-Markov model | Latent-state/duration model, emission process, identification and sampling assumptions. |
| Multitype branching process | Rare-lineage and independence assumptions; offspring law and extinction boundary. |
| Birth-death process | Birth/death law, density dependence, state and population closure. |
| Moran / Wright-Fisher population model | Population size, reproduction clock, selection/drift assumptions. |
| First-passage / competing-boundary analysis | Declared entry and competing exit sets, path semantics and horizon. |
| Transition-path theory | Model-specific path law, boundary sets and stationary or finite-time construction. |
| Large deviations / rare-event model | Explicit scaling, rate/action functional, asymptotic regime and error limitations. |
| Metastability / quasi-stationarity | Definition, conditioned law, reference timescale, entry/residence/exit criteria. |
| Stochastic hybrid system | Well-defined event resets, continuous dynamics and coupling. |
| SDE / jump process | Noise convention, regularity, boundary behavior and numerical scheme. |
| Spatial agent-based model | Local rules, geometry, update order, scale and observation mapping. |
| PDE / reaction-diffusion / SPDE | Continuum validity, boundary/initial conditions, conservation and discretization. |
| Evolutionary game / adaptive dynamics | Biologically justified fitness interactions and frequency dependence. |
| Multistate survival / competing risks | Censoring, observation schedules, entry conditions and estimand-specific hazards. |
| Bayesian hierarchical model | Likelihood, prior provenance, exchangeability/partial pooling and model checks. |
| Phylogenetic / lineage model | Mutation/CNA/SV observation process, ancestral uncertainty and model limitations. |
| Structural causal / partial-identification model | Causal graph, confounding/interference, positivity/consistency and intervention semantics. |
