# Parameter provenance

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

For every material value record meaning, units, uncertainty/prior, context, source, and role: measured, external reference, fitted, calibrated, derived, assumption, normalization, numerical control, sensitivity-only or diagnostic. A fitted constant is not a theory-derived prediction. No cancer parameter values are supplied at bootstrap.
