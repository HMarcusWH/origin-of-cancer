# Persistence estimands

> Basis: OoC v0.1.1; MVCL v1.3; the scoped method imports.

Pathwise first entry, uninterrupted residence, occupation, duration and recurrence are distinct before taking expectations. Probabilistic summaries need a justified path law. An establishment event may combine biological properties and persistence, but is not defined here. Infinite-horizon invariance requires a separate proof; finite trajectories cannot establish it.
