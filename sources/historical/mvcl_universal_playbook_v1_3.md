UNIVERSAL PLAYBOOK — Pan‑Cancer Strategy
(Based on MVCL v1.2)

Overview

This playbook operationalizes the MVCL loop (Seed → Switch → Sink → Spread) into a universal,
pan‑cancer strategy. It defines the four system‑level bottlenecks shared by most lethal tumors and
provides actionable pillars, timing heuristics, monitoring matrices, and lever classes.


Four Pillars (Shared Bottlenecks)

Pillar 1: Deny the Sanctuary (Niche & Immune Shield)

Objective: Collapse the protective niche/immune‑evading environment.

Actions: - Normalize TME (reduce hypoxia, improve vessels, reduce acidity). - Block immunosuppressive
metabolites (lactate/MCT, adenosine/A2A). - Address systemic shields (aging/CHIP, inflammaging).

Monitoring: pH/lactate, A2A expression, vessel maturity, CHIP VAF, SASP.

Levers: LOX/FAK/YAP‑TAZ inhibitors, A2A antagonists, MCT inhibitors, senolytics.


Pillar 2: Crash the Replication Engine (High‑Stress Division)

Objective: Exploit RS/CIN dependence.

Actions: - Stratify by RS/CIN signatures. - Deploy ATR/CHK1/WEE1 inhibitors. - Combine with IO when
cGAS–STING intact.

Monitoring: pCHK1/2, RS signatures, γH2AX, ecDNA, WGD score.

Levers: ATR/CHK1/WEE1 inhibitors, nucleotide pool disruptors.


Pillar 3: Force the Death Decision (Lower Death‑Gate Threshold)

Objective: Push malignant cells into apoptosis.

Actions: - BH3 mimetics (BCL‑2, MCL‑1 inhibitors). - Combine with metabolic stresses.

Monitoring: BH3 profiling, BCL‑2/MCL‑1, glutamine flux.

Levers: Apoptosis sensitizers, glutaminase/IDH inhibitors.

Pillar 4: Block the Escape Route (Plasticity / Tolerance Engine)

Objective: Prevent lineage switches and DTP formation.

       • Plasticity: EZH2/HDAC/CDK7/9 inhibitors; EV pathway blockers.
