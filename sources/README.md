# Source library — reviewer transcriptions

`baseline/` contains the project masters, complete programme, original registry tables
and extracted gap table. `historical/` preserves earlier discovery backbones and
playbook versions without current authority. `methods/` contains internal
methodological sources and isolated upstream OoL code/documents.

The source manifest pins available bytes and derivative representations. Full raw
PDFs, DOCX, ZIPs and large data remain outside the code tree. This is not a publisher
article mirror. No source is automatically qualified for a new cancer use.

The full-text PDF transcriptions have page markers. Equation/table fidelity is not
guaranteed by text extraction; consult the source artifact when a formula is
load-bearing. FFBBP/MCM-HMWH have explicit raw-byte hash gaps.
